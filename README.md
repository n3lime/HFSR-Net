# HFSR-Net

HFSR-Net is an object detection network developed for identifying small-scale unhealthy pine trees in UAV remote-sensing imagery.

## Repository contents

This repository currently provides:

- selected HFSR-Net code components;
- representative previews of the SODP dataset.

## Directory structure

```text
HFSR-Net/
├── models/          # Selected code components
└── data_preview/    # Representative SODP previews
```

## Availability

The repository is intended to provide a concise preview of the proposed method and dataset during the manuscript review stage. Additional materials may be added after publication.
