# HFSR-Net

HFSR-Net is an object detection network developed for identifying diseased pine trees in UAV remote-sensing imagery.

## Dataset Access

The data used in this study can be requested through the [Dataset Access Request](https://docs.google.com/forms/d/e/1FAIpQLSdFuKdgP5Qnv1NZxEqmzBumIaxraToJ5g0hvDb-O3JA3mThlw/viewform) (for registration; access will be provided after the paper is published).

This project was conducted by a research team from the School of Electronic Engineering, Heilongjiang University. We welcome enquiries and academic exchanges.
